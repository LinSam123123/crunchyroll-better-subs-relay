# Crunchyroll Better Subs Relay

ローカル翻訳（実験版）：翻訳設定で「ブラウザー内蔵翻訳（キー不要）」を選び、原文・翻訳先言語を保存して「ローカル翻訳を準備」を押します。初回はブラウザーのモデルをダウンロードします。この設定タブを開いたままプレーヤーに戻って翻訳してください。完了した字幕から表示し、一時停止と再開に対応します。原文が自動の場合は英語を準備し、他の言語は対応ペアを再準備します。利用可否はブラウザー・端末・言語ペアによります。有料サービスへの自動切り替えや作品情報・用語の指示は使用しません。既存のクラウド設定とキーは保持されます。

[中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [AI エージェント向けガイド](AGENTS.md) · [Beta をダウンロード](https://github.com/LinSam123123/crunchyroll-better-subs-relay/releases)

Crunchyroll 用の非公式字幕拡張です。公式の字幕を選んだり、外部の字幕を探したり、合う字幕がないときに自分の翻訳 API を使ったりできます。現在は **お試し用の Beta 版**です。不具合の報告は歓迎しますが、API キーや字幕全文を公開 Issue に貼らないでください。

[Better Subs for Crunchyroll](https://github.com/anitastic-pixel/Better-Subs-for-Crunchyroll) を基に改良しています。原作者 anitastic-pixel に感謝します。Crunchyroll の公式製品でも、原作者が配布している版でもありません。

## 2.7.0.33 の変更

- キー不要のブラウザーローカル翻訳を実験的に追加。初回モデルのダウンロード後も設定タブを開いたまま使用してください。
- ツールバーのポップアップ幅を修正し、多言語の入門ガイドを更新。
- 短い会話や慣用句を誤訳することがあります。既定では無効で、有料サービスへ自動切り替えしません。

## できること

- 音声と公式字幕を組み合わせ、字幕のサイズ、見た目、表示タイミングを調整。
- assrt、SubDL、Jimaku から字幕を検索。ローカルの ASS、SSA、SRT、VTT も読み込めます。
- 「バージョン → 話数」の順に選択。同じ字幕セットを次の話でも使う設定ができます。別のリリースには無断で切り替えません。
- DeepL または自分で選んだ OpenAI 互換 API で翻訳。分割処理、並列処理、ストリーミングに対応し、翻訳済みの部分を先に表示できます。失敗した場合は続きから再試行できます。
- 検索名として公式の地域別名称、登録済みの別名、簡体字・繁体字変換を選択。AI による作品名候補やファイルの話数分析は任意で、確認してから使います。
- 個人の校正用に字幕をエクスポートし、作品情報や用語を翻訳に活用。
- 表示言語は簡体字中国語、繁体字中国語、英語、日本語に対応。初期設定はブラウザーに合わせます。

**翻訳 API がなくても使えます。** 公式字幕やローカルファイルには翻訳キーは不要です。外部字幕サービスの利用には、それぞれのキーが必要です。Jimaku は主に日本語字幕のサービスで、中国語字幕を保証するものではありません。

## インストール：Edge / Chrome

1. [Releases](https://github.com/LinSam123123/crunchyroll-better-subs-relay/releases) から最新の `crunchyroll-better-subs-relay-バージョン番号-beta.zip` をダウンロードし、今後も残しておくフォルダーへ展開します。
2. `edge://extensions` または `chrome://extensions` を開き、「開発者モード」を有効にして「展開して読み込み」を選択します。**manifest.json が直接入っているフォルダー**を指定してください。
3. 元の Better Subs や同種の字幕拡張は一旦無効にしてください。設定を削除する必要はありません。
4. Crunchyroll の再生ページを一度更新します。普段のアカウントでログインし、視聴権限のある作品で利用してください。

ソースコードを取得した場合は `extension/` を直接読み込めます。

## 更新：キーと設定を引き継ぐ

1. 翻訳を停止し、拡張の管理ページで一時的に拡張を無効にします。
2. 新版 ZIP を一時フォルダーに展開し、中のファイルを**元の読み込みフォルダー**へすべて上書きします。フォルダーのパスや `manifest.json` の階層は変更しないでください。
3. 拡張を有効にして再読み込みし、バージョンを確認してから Crunchyroll の再生ページを更新します。

同じブラウザープロファイルと読み込み元を使う更新なら、アンインストールやキーの再入力は不要です。拡張の「削除」は押さず、別のコピーとして追加しないでください。更新後にバックグラウンドが起動しない場合は、未保存の入力を保存してブラウザーをバックグラウンドも含め完全に終了し、開き直してください。拡張のストレージを消去したり、ブラウザーのセキュリティ機能を無効にしたりする必要はありません。

## 使い始めるには

**表示言語を選ぶ：** 拡張のポップアップや翻訳設定の「表示言語」で選択します。言語パックは同梱されており、API は不要です。字幕の原文・翻訳先言語やキーの設定は変わりません。

**まずは公式字幕：** プレーヤーの Better Subs メニューで、希望する言語の公式字幕があるか確認します。

**外部字幕を探す：** 「外部字幕」を開き、使うサービスのキーを設定します。作品、シーズン、話数と検索名を確認して検索してください。ディレクトリを選んだら、バージョンと現在の話のファイルを選び、プレビューしてプレーヤーに読み込みます。次の話も同じセットを使う場合は、字幕セットの追従を選んでから読み込みます。assrt を利用する場合、字幕サービスは assrt.net が提供します。

タイミングがずれている場合は 100ms 単位で調整できます。ただし BD、Netflix、AT-X と Crunchyroll では編集が違うことがあり、一定のオフセットだけでは全編を合わせられません。まず映像に近いバージョンを選んでください。

**合う字幕がない：** 翻訳設定で DeepL または互換 API を選びます。互換 API には Base URL（例：`https://relay.example/v1`）、キー、モデル名、対応プロトコルを入力します。モデルはサービス提供者が用意するもので、この拡張が提供するものではありません。少量で試し、最初は 1 回 15 行、並列数 1、タイムアウト 60 秒程度から調整すると確認しやすくなります。ストリーミングは API 側の対応も必要です。

**作品名や話数を認識できない：** 公式名、英語・日本語名、簡繁変換、手入力を先に試してください。必要な場合だけ API 分析を押します。DeepL はこの分析には使えません。分析を使わないか、別の互換 API を分析用に設定できます。AI の候補は正解を保証しないため、内容を確認してから確定してください。

## キーとプライバシー

- リポジトリと配布 ZIP に使えるキーは含めていません。自分のアカウントを使用します。キーは拡張のローカルストレージに保存されますが、**暗号化された保管庫ではありません**。
- クラウド翻訳では字幕を選択した DeepL / API 提供者へ送ります。ローカル翻訳ではこれらのサービスに字幕を送信しませんが、初回モデルのダウンロードには通信が必要です。AI 分析では関連する作品情報やファイル名を分析用 API へ送ります。
- 字幕検索では検索語を各字幕サービスへ送信し、ダウンロード時はファイルサーバーへ接続します。作品情報の照会では Bangumi、公式の地域別名称では Crunchyroll へ接続します。簡繁変換はオフラインです。
- ページを開く、次の話へ進む、字幕検索が失敗する、といった操作だけで有料翻訳や AI 分析は自動実行されません。各サービスの料金とプライバシー条件を確認してください。
- サービスのドメインへのアクセス権限は必要に応じて要求します。不明な API に本物のキーを入力しないでください。スクリーンショットを公開する前にキー、アカウント、期限付きリンクを隠してください。
- アニメ動画や完成済み字幕を同梱しません。契約、地域制限、DRM を回避する機能はありません。外部字幕の利用可否と権利は提供元に従います。

## 既知の制限

- 表示言語を変更しても、字幕ファイル名、作品名、字幕本文や入力済みの作品情報はそのままです。外部サービスからのデータも別の言語で表示される場合があります。
- 公式の地域別名称は取得できない場合があります。リダイレクトや地域・言語制限の影響を受けます。簡繁変換は現地で一般的な作品名とは限りません。
- 特別編、同じ話の複数修正版、欠番、曖昧な命名は手動選択が必要です。自動追従は確認済みの作品・シーズン・バージョンに限ります。
- 外部字幕と動画が自動的に一致する保証はありません。異なる言語を使った自動タイムライン整合は未実装です。
- 字幕サービスの制限や障害、作品未収録、機械翻訳の誤訳があり得ます。別の版、ローカル読み込み、小さい翻訳バッチを試せます。
- 自動テストは分離された模擬プレーヤー / API を使用します。全作品や実環境を検証したという意味ではありません。字幕が出ない場合は、同種の拡張を無効にし、再生ページを更新して確認してください。

## 報告・開発

[Issues](https://github.com/LinSam123123/crunchyroll-better-subs-relay/issues) に拡張とブラウザーのバージョン、再現手順、秘密情報を除いたエラーを記載してください。キー、字幕全文、ログイン Cookie、個人のブラウザーフォルダーは添付しないでください。

開発には Node.js 22 以降と npm を使用します。

```sh
npm ci
npm run verify
npm run privacy
npm run package
```
