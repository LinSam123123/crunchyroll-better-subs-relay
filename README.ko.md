# Crunchyroll Better Subs Relay

로컬 번역(실험 기능): 번역 설정에서 Browser local translation (no key)을 선택하고 원문과 번역 언어를 저장한 다음 Prepare local translation을 누르세요. 처음에는 브라우저 언어 모델을 다운로드합니다. 설정 탭을 열어 둔 채 플레이어로 돌아가 번역하세요. 완료된 자막부터 표시하며 일시 정지와 이어 번역을 지원합니다. 원문 자동 선택은 영어를 준비하므로 다른 언어는 해당 언어 쌍을 다시 준비해야 합니다. 브라우저·기기·언어 쌍에 따라 지원 여부가 다릅니다. 유료 서비스로 자동 전환하지 않으며 작품 정보나 용어 지시는 사용하지 않습니다. 기존 클라우드 설정과 키는 유지됩니다.

Crunchyroll용 비공식 자막 확장 프로그램입니다. 공식 자막을 선택하거나 외부 자막을 찾을 수 있으며, 적절한 자막이 없으면 본인의 번역 API로 번역할 수 있습니다. 현재는 **체험용 Beta 버전**입니다. 의견과 오류 제보를 환영하지만, 공개 이슈에 API 키나 자막 전체를 올리지 마세요.

[Better Subs for Crunchyroll](https://github.com/anitastic-pixel/Better-Subs-for-Crunchyroll)을 기반으로 개선했습니다. 원작자 anitastic-pixel에게 감사드립니다. Crunchyroll이나 원작자가 공식 배포하는 버전은 아닙니다.

## 2.7.0.33 변경 사항

- API 키 없이 사용하는 실험적 브라우저 로컬 번역을 추가했습니다. 처음 모델을 다운로드하고 번역 설정 탭을 열어 두세요.
- 도구 모음 팝업의 좁은 너비를 수정하고 다국어 사용 안내를 보완했습니다.
- 짧은 대사와 관용구를 잘못 번역할 수 있습니다. 기본으로 활성화되지 않으며 유료 서비스로 자동 전환하지 않습니다.
- 로컬 번역은 클라우드 번역 서비스에 자막을 보내지 않습니다. 최초 모델 다운로드에는 인터넷이 필요합니다.

## 주요 기능

- 음성과 공식 자막의 언어를 조합하고, 자막 크기·스타일·표시 시간을 조정할 수 있습니다.
- assrt, SubDL, Jimaku에서 자막을 검색하거나 로컬 ASS, SSA, SRT, VTT 파일을 불러올 수 있습니다.
- 배포 버전과 회차를 선택하고, 다음 회차에서도 같은 자막 모음을 이어서 사용할 수 있습니다. 다른 배포 버전으로 임의 변경하지 않으며, 시간 오프셋도 선택적으로 이어받습니다.
- DeepL 또는 원하는 OpenAI 호환 API로 번역할 수 있습니다. 배치 처리, 동시 요청, 스트리밍, 번역된 부분 먼저 표시, 미완료 부분 이어 번역을 지원합니다.
- 지역별 공식 작품명, 저장한 별칭, 오프라인 중국어 간체·번체 변환으로 검색 이름을 선택할 수 있습니다. AI 작품명·파일 회차 분석은 선택 사항이며, 후보를 확인한 뒤 적용합니다.
- 개인 교정용 자막을 내보내고, 작품 정보와 용어를 번역에 활용할 수 있습니다.
- 인터페이스는 영어, 일본어, 중국어 간체·번체를 지원합니다. 기본값은 브라우저 언어이며, 자막 언어와 별도로 선택할 수 있습니다.

**번역 API가 없어도 사용할 수 있습니다.** 공식 자막과 로컬 파일에는 번역 키가 필요하지 않습니다. 외부 자막 서비스는 각각의 키가 필요합니다. Jimaku는 주로 일본어 자막을 제공하며, 다른 언어의 자막은 보장하지 않습니다. 이 페이지는 한국어 사용 설명서이며, **플러그인 인터페이스는 아직 한국어를 지원하지 않습니다.**

## Edge / Chrome에 설치하기

1. [Releases](https://github.com/LinSam123123/crunchyroll-better-subs-relay/releases)에서 `crunchyroll-better-subs-relay-버전번호-beta.zip`을 다운로드한 뒤, 계속 보관할 폴더에 압축을 풉니다.
2. `edge://extensions` 또는 `chrome://extensions`에서 개발자 모드를 켜고, 압축 해제된 확장 프로그램을 로드합니다. **`manifest.json`이 바로 들어 있는 폴더**를 선택하세요.
3. 충돌을 피하려면 기존 Better Subs와 비슷한 자막 확장 프로그램을 일시적으로 끕니다. 기존 설정을 삭제할 필요는 없습니다.
4. Crunchyroll 재생 페이지를 새로고침합니다. 본인의 계정으로 시청 권한이 있는 콘텐츠를 이용하세요.

소스 코드로 설치하는 경우 저장소의 `extension/` 폴더를 직접 선택할 수 있습니다.

## 키와 설정을 유지하며 업데이트하기

1. 번역을 중지하고 확장 프로그램 관리 페이지에서 프로그램을 일시적으로 끕니다.
2. 새 ZIP을 임시 폴더에 풀고, 내부 파일 전체를 **기존에 로드한 폴더**에 덮어씁니다. 폴더 경로와 `manifest.json`의 위치를 유지하고, 폴더가 한 단계 더 중첩되지 않도록 주의하세요.
3. 확장 프로그램을 다시 켜고 다시 로드한 뒤, 버전을 확인하고 재생 페이지를 새로고침합니다.

같은 브라우저 프로필과 기존 경로에서 업데이트하면 재설치하거나 키를 다시 입력할 필요가 없습니다. 업데이트를 위해 확장 프로그램의 삭제 버튼을 누르거나 별도의 복사본을 추가하지 마세요. 업데이트 후 백그라운드가 시작되지 않으면 작성 중인 내용을 저장하고, 백그라운드 실행을 포함해 브라우저를 완전히 종료한 뒤 다시 여세요. 확장 프로그램 저장소를 지우거나 브라우저 보안 기능을 끄지 마세요.

## 사용 시작하기

**인터페이스 언어:** 확장 프로그램 팝업이나 번역 설정에서 언어를 선택합니다. 언어팩은 프로그램에 포함되어 있어 API가 필요하지 않으며, 자막 원문·번역 대상 언어·API 설정은 바뀌지 않습니다.

**공식 자막:** 먼저 플레이어의 Better Subs 메뉴에서 원하는 언어의 공식 자막이 있는지 확인하세요.

**외부 자막:** 외부 자막 페이지를 열어 사용할 서비스의 키를 설정합니다. 작품, 시즌, 회차, 검색 이름을 확인한 뒤 검색하세요. 디렉터리, 배포 버전, 현재 회차 파일을 선택하고 미리 본 다음 플레이어에 적용합니다. 다음 회차에도 같은 모음을 쓰려면 적용하기 전에 자막 모음 자동 따라가기를 선택하세요. assrt 이용 시 자막 서비스는 assrt.net에서 제공합니다.

싱크가 어긋나면 100ms 단위로 조정할 수 있습니다. BD, Netflix, AT-X, Crunchyroll은 편집이 다를 수 있어, 하나의 오프셋만으로 전체 회차를 맞추지 못할 수 있습니다. 먼저 영상과 가까운 배포 버전을 선택하세요.

**기계 번역:** DeepL 또는 사용자 지정 호환 API를 선택합니다. 사용자 지정 서비스는 Base URL(예: `https://relay.example/v1`), 키, 모델, 지원 프로토콜을 입력합니다. 모델은 서비스 제공자가 제공하며, 이 확장 프로그램에서 제공하지 않습니다. 소량으로 먼저 확인하고, 배치당 15줄·동시 요청 1개·제한 시간 60초 정도에서 조정할 수 있습니다. 스트리밍은 API 제공자의 지원도 필요합니다.

**작품명이나 파일 회차가 인식되지 않을 때:** 공식명, 영어·일본어 이름, 간체·번체 변환, 직접 수정을 먼저 시도하세요. 필요한 경우에만 API 분석을 실행합니다. DeepL은 이 분석을 지원하지 않으므로 사용하지 않아도 되며, 별도의 호환 API를 분석용으로 설정할 수도 있습니다. AI 결과는 후보이므로 확인 후 적용하세요.

## 키와 개인정보

- 저장소와 설치 파일에는 사용할 수 있는 키가 포함되어 있지 않습니다. 각자 본인의 계정을 사용합니다. 키는 확장 프로그램의 로컬 저장소에 보관되며, **암호화된 금고가 아닙니다**.
- 번역할 때 자막 텍스트를 선택한 DeepL 또는 API 제공자에게 보냅니다. AI 분석은 관련 작품 정보나 파일명을 설정한 분석 서비스에 보냅니다.
- 자막 검색은 선택한 서비스에 검색어를 전송하고, 다운로드는 파일 서버에 연결합니다. 작품 정보 조회는 Bangumi, 공식 지역별 작품명 조회는 Crunchyroll에 연결합니다. 간체·번체 변환은 오프라인에서 처리합니다.
- 페이지를 열거나 다음 회차로 이동하거나 검색에 실패해도 유료 번역과 AI 분석이 자동 실행되지 않습니다. 각 서비스의 요금과 개인정보 처리 조건을 확인하세요.
- 서비스 도메인 접근 권한은 필요한 경우에 요청합니다. 모르는 API 서비스에 실제 키를 입력하지 마세요. 스크린샷을 공개하기 전에 키, 계정 정보, 임시 다운로드 링크를 가리세요.
- 애니메이션 영상이나 완성된 자막 모음을 배포하지 않으며, 구독·지역 제한·DRM을 우회하지 않습니다. 외부 자막의 이용 가능 여부와 사용 권리는 제공처에 따릅니다.

## 알려진 제한

- 인터페이스 언어를 바꿔도 파일명, 작품명, 자막 본문, 직접 입력한 정보는 그대로 유지됩니다. 외부 서비스 결과도 다른 언어일 수 있습니다.
- 공식 지역별 이름은 언어·지역 제한이나 리디렉션으로 가져오지 못할 수 있습니다. 간체·번체 변환 결과가 현지의 통용 작품명과 같다는 보장은 없습니다.
- 특별편, 누락된 회차, 모호한 파일명, 여러 수정본은 직접 선택해야 할 수 있습니다. 자동 따라가기는 확인한 작품·시즌·배포 버전에 한정됩니다.
- 외부 자막이 현재 영상과 자동으로 맞는다는 보장은 없습니다. 서로 다른 언어를 이용한 자동 타임라인 정렬은 아직 구현되지 않았습니다.
- 자막 서비스는 검색 결과가 없거나 요청 제한·장애가 있을 수 있으며, 기계 번역도 오역할 수 있습니다. 다른 버전, 로컬 파일, 작은 번역 배치를 대안으로 사용할 수 있습니다.
- 자동 브라우저 테스트는 격리된 모의 플레이어와 API를 사용하며, 모든 실제 계정·작품·브라우저 환경을 검증한 것은 아닙니다.
